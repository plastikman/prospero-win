## Hardware smoke-test order

Use the same installed package and existing profiles for all titles:

1. Oblivion: control for relocation, filesystem reads, input, and native WoW64 startup.
2. GTA IV: second control for DXVK and the existing display workaround.
3. Fallout 3: exercise the direct-memory heap settings over a sustained session.
4. Fallout: New Vegas: use the native profile; check load, gameplay, and multiple V.A.T.S. entries.

Record each title's launch result and selected CPU mode. For an FNV translator comparison, explicitly confirm `wowprospero.dll` and the `BTCpuSimulate` trace rather than relying on the profile request.

This package's `kernelbase.dll` does not contain the optional `PW_EXCEPTION32` guest-fault context records. Do not infer a guest fault from klog alone; retain the package-matched binaries and use the in-process diagnostics that are present if a launch fails.
